# Bootstrap Design Demo

A simple Bootstrap-based landing page with HTML and CSS.

## Files
- `index.html` - page structure
- `styles.css` - custom styling

## Run locally
Open `index.html` in a browser, or serve the folder with a simple web server.

## Publish to GitHub Pages
1. Create a new GitHub repository.
2. Push the contents of this folder to the repository.
3. In GitHub, open Settings > Pages and publish from the main branch.
